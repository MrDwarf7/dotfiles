# installed_tools

Package-list exports for this machine. Generated by `export.sh`
(runs `pacman -Q*` variants, dumps into this dir). Re-run after
installs to refresh before a drive migration.

## Files

| File | Source command | Use |
|------|---------------|-----|
| paru_explicit_package.txt | `pacman -Qe` | explicit installs - the reinstall set |
| aur_packages.txt | `pacman -Qm` | foreign / AUR pkgs - reinstall via AUR helper |
| pacman_native_packages.txt | `pacman -Qn` | native (repo) pkgs only |
| pacman_installed_packages.txt | `pacman -Q` | full list (name+ver) |
| paru_installed_packages.txt | `pacman -Q` | full list (compat name) |
| packages_name_only.txt | `pacman -Qq` | names only |

## Reinstall on a fresh Arch install

Native + explicit (repo) packages:

    sudo pacman -S --needed $(awk '{print $1}' paru_explicit_package.txt)

AUR packages (needs paru / your AUR helper):

    paru -S --needed $(awk '{print $1}' aur_packages.txt)

## Note

Packages from dedicated tools (mise, cargo-binstall, pipx, npm -g,
etc.) are NOT covered by these exports - they are handled by those
tools. Track those separately (their own export commands) before
migrating, or you will lose them on the new drive.

The `command.txt` helper holds the original reinstall one-liner for
reference.
